# Kiem thu CSDL

Thu muc nay danh cho cac script kiem thu nghiep vu. Cac bai kiem thu can duoc tach rieng va ghi ro: du lieu dau vao, thao tac, ket qua mong doi, ket qua thuc te.

Khong dua lenh kiem thu lam thay doi du lieu that neu chua co transaction va rollback ro rang. Chua tao cac test SQL moi trong dot sap xep nay de tranh khang dinh ket qua chua chay.
