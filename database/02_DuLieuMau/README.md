# Du lieu mau

File `schema_full_backup.sql` la ban dump chi gom cau truc (schema-only), khong chua cac lenh `INSERT` hoac `COPY` de nap du lieu.

Du lieu mau hien dang duoc quan ly truc tiep tren Supabase. Chua tao `seed.sql` de tranh tu y thay doi hoac tao sai du lieu. Khi can tai tao CSDL tren moi truong khac, hay xuat data rieng tu Supabase sau khi thong nhat pham vi du lieu can chia se.
